# DejaVu Sans

Unmodified DejaVu Sans 2.37, from Ubuntu's `fonts-dejavu-core` package.
Source: https://dejavu-fonts.github.io/

The Bitstream Vera license and public-domain notice for DejaVu changes are
preserved in `LICENSE-DejaVu.txt`. The file includes the package's copyright
notice. No Microsoft fonts or original game fonts are bundled here.

`DejaVuSans.ttf` SHA-256:
`ae7b7855e115a5966d8b1b3f80f254ccc117ec86f9965e202ee2940453837280`.

The font is used only by the new library frontend. Native game HUDs/fonts remain
in their original runtime and resource sets.
